# Elite UPI QR Card Generator 💳⚡

An ultra-premium, high-definition single-page Web Application designed for generating high-gloss Metallic Deep Emerald UPI Payment Terminal Cards with real-time dynamic QR generation and 4K PNG export.

Designed and Developed by **Vikas Mishra**.

## ✨ Features
- **Deep Emerald Metallic Glass UI**: Interactive canvas background with node particles and shimmering metallic gradients.
- **Real-Time Dynamic QR Engine**: Instant updating on amount, note, or UPI handle modification without page refreshes.
- **Standardized Payment Link**: Formatted via official `upi://pay` specs compatible with Google Pay, PhonePe, Paytm, and BHIM.
- **Native Vector Payment SVGs**: Embedded vector graphics ensure pixel-perfect 4K PNG capture via `html2canvas` without blur or logo truncation.
- **Mobile Responsive**: Perfect layout optimization across all smartphone, tablet, and desktop viewports.

## 🚀 1-Click Render Static Site Deployment
1. Push this repository to GitHub.
2. Log into [Render Dashboard](https://dashboard.render.com/).
3. Click **New +** -> **Static Site**.
4. Connect your GitHub repository.
5. Render will automatically detect `render.yaml` and deploy instantly with **Zero Configuration**.
